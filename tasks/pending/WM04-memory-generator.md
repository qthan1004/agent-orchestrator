### 3. Key behaviors

**Learnings preservation:**
- `extractLearningsSection()` reads existing `workspace-memory.md`
- Extracts everything from `## Agent Learnings` to end of file (or next `## `)
- `generateMemory()` appends preserved learnings to output
- Nếu không có learnings → output empty section với HTML comments

**File Map improvements (vs current):**
- Thêm column `Modified` (last modified date from stat)
- Max 50 files (plan says max 50, sorted by relevance)
- Sort by relevance: source > config > docs > test > other

**Architecture Relationships:**
- Format co-change patterns as human-readable relationships
- Include direction arrows (←→ for co-change, → for dependency)
- Add brief annotation explaining the relationship (optional, nếu dễ infer)

**Project Overview enhancements:**
- Detect `entry` from file scanner (files with type 'entry')
- Detect `tech_stack` from package.json dependencies
- Detect `type` (Node.js MCP server, React app, etc.)
